Cómo descargar y usar este proyecto

### Opción 1 — Descargar archivo ZIP
1. En la página principal del repositorio, haz clic en el botón verde **"Código"**
2. Selecciona **"Descargar ZIP"**
3. Descomprime el archivo en tu computadora

### Opción 2 — Clonar con Git

```
git clone https://github.com/tu-usuario/Detector_Casco_Operario.git
```

---

### Cómo ejecutar el programa

1. **Instalar Python** — descárgalo desde [python.org/downloads](https://python.org/downloads) y marca "Add Python to PATH" al instalar
2. **Instalar OpenCV** — abre la consola y escribe:

```
pip install opencv-python
```

3. **Ejecutar el detector** — en la carpeta del proyecto:

```
python Detector_Casco_Operario_V2.py
```

---

### Notas

- Necesitas una cámara web o DroidCam
- No muevas el archivo `cascade.xml` de su carpeta
- Si la cámara no abre, verifica que ningún otro programa la esté usando
- Que el código IP del python sea el que aparece en el DroidCam de tu dispositivo móvil
